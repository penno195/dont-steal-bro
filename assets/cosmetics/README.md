# Cosmetic art (next-stages step 10)

Generated by `scripts/make-cosmetic-art.ps1`; re-run it to regenerate.
White images are tinted in game by the item's colour, so they look blank
on a white background. That is intended.

## Status

All the images were uploaded on 2026-10-03 to the owner's account
through Studio MCP's `upload_image`. Their ids are in the configs, and
every item they cover is enabled. Two things are still open; each needs
a Studio step only the owner can do (see below):

- `rubber-duck.obj` → `RubberDuckProjectile.projectileMeshAssetId`. In
  Studio, `AssetService:CreateAssetAsync` returns "not available yet",
  so the mesh can't be uploaded from a script.
- the Victory Flex animation → `VictoryFlexEmote.animationAssetId`.

Paste each id in, then set that item's `enabled = true`.

## Upload, then paste the ids back

Images: Studio **Asset Manager → Import** (or Creator Hub → Development
Items → Decals). The config needs the **Image** id. A Decal's id is a
different number, so if you go through Creator Hub, open the decal and use
the image id it points at.

| File | Config | Field |
|---|---|---|
| `founder-trail.png` | `FounderTrail` | `trailTextureAssetId` |
| `founder-shirt.png` | `FounderSkin` | `shirtAssetId` |
| `founder-pants.png` | `FounderSkin` | `pantsAssetId` |
| *(Studio, see below)* | `VictoryFlexEmote` | `animationAssetId` |
| `podium-sparkle.png` | `ChampionPodiumFlare` | `podiumTextureAssetId` |
| `gilded-nameplate.png` | `GildedNameplate` | `nameplateFrameAssetId` |
| `sorry-not-sorry-card.png` | `SorryNotSorryCard` | `cardImageAssetId` |
| `vault-door.png` | `VaultDoorReveal` | `revealTextureAssetId` |
| `duck-burst.png` | `RubberDuckProjectile` | `explosionTextureAssetId` |
| `rubber-duck.obj` | `RubberDuckProjectile` | `projectileMeshAssetId` |
| `wildfire-flair.png` | `WildfireStreakFlair` | `flairTextureAssetId` |

The first three are Season 1's premium track.

- **Shirt and pants** are uploaded as plain images, not as catalog
  clothing. `CosmeticService` sets the template on an in-game Shirt and
  Pants, so the image id is enough and there's no upload fee.
- **Duck mesh**: Studio **File → Import 3D** with `rubber-duck.obj`, then
  copy the number from the imported MeshPart's `MeshId`. It has no
  texture because the game colours it with the power-up's role colour.
- **Victory Flex** is built in Match.rbxl as a temporary rig called
  `Workspace.VictoryFlexRig`. Its 2.2 s KeyframeSequence is saved in
  `ServerStorage.RBX_ANIMSAVES.VictoryFlexRig`. Open the Animation Editor,
  select the rig, load **VictoryFlex**, then **Publish to Roblox**. Then
  delete the rig and that `RBX_ANIMSAVES` entry. The animation must be
  owned by the same user or group as the experience, or it won't play.

Upload everything under the account or group that will own the
experience.
