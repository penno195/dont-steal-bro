Decision Studio Build Plan

Fifty-seven tickable production tasks across ten phases, each with a ready-to-paste prompt and a model recommendation. Phases are a sequence, not a menu — the gate note under each one is the condition for starting the next. Ticks are saved, so this doubles as your burndown.

Opus 5

Architecture, state machines, anti-exploit, DataStore correctness, anything where a subtle bug costs player data or competitive fairness. Turn on Fast mode for long sessions.

Sonnet 5

The bulk of implementation against a spec that already exists: UI components, task and power-up modules, content generation from a template, test suites.

Haiku 4.5

Mechanical, high-volume, low-ambiguity work: config stubs, builder scripts, registry files, formatting and repetitive scaffolding. Cheap enough to re-run.

Before you paste any prompt

  1. Attach docs/gdd.md and docs/architecture.md from the dont-steal-bro repo to every session — most prompts below assume that context, and the architecture doc is what stops each session re-inventing the folder structure.
  2. Work in the repo with Claude Code so the model reads real files instead of guessing at your codebase.
  3. Every prompt ends with an acceptance line. Don't tick the box until that line is actually true in Studio, not just in the diff.
  4. Luau is a smaller slice of training data than TypeScript. Expect to correct Roblox API details, and always verify against current docs.
Tick state is shared with anyone who can open this page, and saved as you go. Filters and open prompts are yours alone.
