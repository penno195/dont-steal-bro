What changes in the Luau

  • Tokens.luau gains gradient pairs (primaryTop/primaryBottom), a lip colour per fill, stroke widths and a display font.
  • Base.luau gets two helpers: lipSurface (surface + offset lip frame) and gloss (white UIGradient overlay).
  • Button, IconButton, Panel, Modal, TabBar, CurrencyPill, ProgressBar, Toast, PlayerRow pick these up. Screens barely change.

Constraints kept

  • Steal/Share hexes, labels, icons and sides unchanged.
  • Theme.spec contrast checks still apply: each ink is checked against both gradient stops.
  • No streaks, titles or flair in the race HUD (Q7).
  • Touch sizes unchanged: 56 primary, 44 compact/icon.

Cost on a cheap phone

  • Gradients and strokes are cheap. Each lip adds one Frame per button, so roughly +20 instances on the busiest screen.
  • A soft drop shadow would need a 9-slice image. All three directions skip it and use hard lips instead.
